# Chef Express — Plataforma de Gastronomia Sob Demanda

TCC Devs2Blu. Plataforma web que conecta clientes a profissionais de gastronomia autônomos
(cozinheiros e chefs) para eventos e marmitas semanais: busca com filtros, negociação com
proposta, pagamento simulado e avaliação pós-serviço.

**Stack:** Angular · C# (.NET) · MariaDB

## Fluxo de trabalho

- `main` recebe apenas código revisado, via Pull Request.
- Cada integrante trabalha em uma branch própria (ex.: `gabriel/backend-foundation`) e abre um PR para a `main`.
